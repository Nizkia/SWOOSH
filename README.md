**SWOOSH – Campus Runner System**

A delivery & pickup service app for students, built using Android Studio (Java) + Firebase.


**⭐ Overview**

SWOOSH is a runner-style mobile app designed for university students. It allows users to request services such as:

Parcel pickup from student center (PPP)

Food delivery (GrabFood, ShopeeFood, FoodPanda simulation)

Printing delivery service

This was a Workshop & Showcase project developed in Android Studio using Java, with Firebase as the backend.

I was the team leader and completed roughly 90% of the coding, while managing my team’s tasks.
